🎬 Movie Recommendation System

A Content-Based Movie Recommendation System built using Python and Machine Learning. It recommends movies similar to the movie selected by the user.

🚀 Features

- 🎥 Movie recommendations based on content similarity
- 🔤 TF-IDF for text feature extraction
- 📐 Cosine Similarity for finding similar movies
- 🌐 Interactive Streamlit web application
- 🖼️ Movie posters using TMDB API

🛠️ Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit
- TMDB API

⚙️ How It Works

Dataset
   ↓
Data Cleaning
   ↓
Tags Creation
   ↓
TF-IDF
   ↓
Cosine Similarity
   ↓
Movie Recommendations
   ↓
Streamlit App

▶️ Run the Project

Install the required libraries:

pip install -r requirements.txt

Run the application:

python -m streamlit run app.py
